# Not a Framework

The kit has no required runtime, package manager, framework, database, hosting platform, or Git model.

It is a portable workflow and context kit. The destination project chooses its own technology, architecture, and delivery process.

Presentation of Pathfinder-generated visual artifacts is the one choice Pathfinder keeps: they use its own renderer and presentation contract. Generating one is optional and needs Node; nothing else in the workflow does.
