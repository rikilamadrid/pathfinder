# Not a Framework

The kit has no required runtime, package manager, framework, database, hosting platform, or Git model.

It is a portable workflow and context kit. The destination project chooses its own technology, architecture, and delivery process.

Presentation of Pathfinder-generated visual artifacts is the one choice Pathfinder keeps: they use its own renderer and presentation contract. Generating one is optional and needs Node. Orchestrator mode also uses a Node engine and Git, plus `gh` for GitHub Issues; human-in-the-loop delivery needs no runtime. Neither engine becomes an application dependency.
