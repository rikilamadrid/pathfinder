- `orchestrate status` now flags a Complete ticket that still holds a claim:
  the row stays `integrated` and its gate starts with `claim retained`, in
  text and `--json` output. That is detection, not release eligibility. Where
  the claim data already shows release would refuse (a branch checked out
  outside `.pathfinder`, no branch left, or a worktree off its ticket branch)
  the gate says a person decides; otherwise it reads
  `orchestrate release <key> releases it only if its branch is proven merged
  and its worktree is clean`. A gate question or profile diagnostic already
  on the row is kept after the hint. Advisory only: `status` never releases
  anything, and a Complete ticket without a claim is shown as before.
