- A ticket role may now cite its own earlier successful full-suite run instead
  of re-running it, but only when the role and session are the same, `HEAD` is
  unchanged, `git status --porcelain` was and is empty, the run exited 0, and
  no dependency, lockfile, environment or install change happened since. The
  citation is one line,
  `suite: <command> | head <sha> | clean | exit 0 | <counts> | <UTC time>`.
  A dirty tree is never reused. Focused tests after an edit, any run after a
  change, another role's or another session's run, the Tester's own run,
  Adversary experiments, CI, `complete`'s post-merge checks, and any re-run
  after a failure always run fresh (`skills/ticket/SKILL.md` §Full-suite
  reuse).
