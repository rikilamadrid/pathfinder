- Release notes for Pathfinder's own changes are now one new
  `changelog.d/<ticket-key-or-branch-slug>.md` fragment per change instead of
  an edit to `CHANGELOG.md`, so concurrent tickets no longer collide on one
  `[Unreleased]` hunk. `.github/scripts/assemble-changelog.py`, run as the
  first release step, appends the fragments in filename order to
  `[Unreleased]` and removes them. It is idempotent, and it refuses, changing
  nothing, a duplicate, a bad name, or a fragment that is not `- ` bullets.
  Repository workflow only: destination projects and shipped skills are
  unchanged.
