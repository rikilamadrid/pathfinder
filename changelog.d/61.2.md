- `orchestrate dispatch-check <key> --session <s> --harness <h> --brief <brief.json>`
  checks what a finished worker session actually ran on against the brief it
  was started from, and appends one line under `## Dispatches` in the claim's
  `current-ticket.md`: planned, invoked and observed model/effort,
  `match|mismatch|inherited`, tokens and elapsed time, and the evidence source.
  For Claude Code it reads the subagent transcript's `api-request` entries
  (`params.model`, `params.output_config.effort`), cross-checks the assistant
  entries and counts usage once per message. Output tokens are final only
  where a message carries a `stop_reason`; otherwise the transcript holds a
  streaming-start placeholder and the output is recorded as a lower bound,
  `out >=<n>`. Other harnesses declare an observation with
  `--observed-model`, `--observed-effort` and `--source`. A mismatch exits 1,
  and a transcript that is not evidence — including one whose requests
  produced no model response, as after an API error — is refused, recording
  nothing; a transcript file name that would break the one-line record is a
  usage error. `orchestrate start` treats either as an unusable report and
  opens the human gate with the line.
- `orchestrate brief` accepts a human override, `--model <m> --effort <e>`,
  only together with `--override "<the human's words>"`; it replaces the
  selection for that one brief and is translated or refused as usual.
  `brief --json` now also prints `routing: { selected, override }`.
