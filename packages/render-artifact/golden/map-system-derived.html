    Paths

    From an edit to a surface

    Five steps, and the last one is the point: the generated adapter carries a pointer back to the canonical file rather than a copy of it.

    Walks
    1. A maintainer triggers generate-adapters.mjs — regenerates
    2. generate-adapters.mjs calls planAdapters() — plans adapters
    3. planAdapters() becomes applyAdapterPlan() — once planned
    4. applyAdapterPlan() writes .claude/skills/ — adapter
    5. .claude/skills/ depends on skills/NAME/SKILL.md — points at
    Evidence
    • CLAUDE.mdlines 78–82

    How drift is caught

    CI asks the shipped generator whether the committed adapters are what it would write now, so a stale adapter fails a pull request rather than reaching a reader.

    Walks
    1. The validate workflow triggers validate-kit.py — every change
    2. validate-kit.py calls generate-adapters.mjs — is this stale?
