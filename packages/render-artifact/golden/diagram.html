Paths

A clean run

Four transitions, each performed by a different action, and the last one only after a human has accepted the work.

Walks
  1. Proposed becomes Ready — ticket load
  2. Ready becomes In Progress — ticket start
  3. In Progress becomes Review — ticket review
  4. Review becomes Complete — human accepts
Evidence
  • skills/ticket/SKILL.mdlines 43–49

Review sends it back

Review reports findings and changes no implementation, so the ticket returns to the session that holds it rather than to a new one.

Walks
  1. In Progress becomes Review — ticket review
  2. Review becomes In Progress — changes requested
